  • Metric: [← →]
  • Sequence Accuracy Plot: [← →]
x-axis: true allele size — positive = expansion, negative = contraction.
Left panel: distribution of the per-allele edit distance in each x bin (box = median and IQR).
Right panel: fraction of alleles in each edit-distance category.
Gray: tool produced no allele sequence for this allele.
Green: the reported sequence matches the truth sequence exactly.
Yellow → red: increasingly large edit distance.
Metric: "edit distance (bp)" is the raw Levenshtein distance; "normalized" divides it by the length of the true allele sequence, so a 5bp error counts differently on a 40bp allele than on a 4kb one.
NOTE: Only TRGT v5, ATaRVa and HipSTR report an allele sequence in their output VCF, so only they can be scored this way; every other tool reports a repeat count only. HipSTR is a short-read caller, so its numbers are not comparable to the long-read tools — the Sequencing Type selector keeps them in separate plots. ATaRVa's reported sequence is a partial-order-alignment consensus of the reads supporting each allele rather than an assembled haplotype, so a small non-zero floor relative to TRGT is expected rather than a pipeline error.
